Online Learning Platform Interaction Analysis

A simple graph-based study of student activity, interaction strength, and network structure across three learning groups: ICS, CD, and PS.

Project goal

To understand how students connect inside the platform and which students are the most active.

What is a network?

Students are shown as nodes and interactions as links between them.

What was found?

Most active students, isolated students, and comparison across the three networks.

ML Results

Linear Regression

This model predicts a student’s total interaction weight using features like interaction count and network type. It learns the relationship between these features and the target value total_weight.

  • Model type: Linear Regression
  • Target: total_weight
  • Features: interaction_count + network
  • Split: 80% train / 20% test
  • Goal: Predict student interaction strength
MAE5.1483
RMSE7.6487
R²0.8930

Decision Tree

This model also predicts a student’s total interaction weight, but it learns a tree-based decision pattern instead of a straight-line equation. It is useful for capturing non-linear relationships in the same dataset.

  • Model type: Decision Tree Regressor
  • Target: total_weight
  • Features: interaction_count + network
  • Split: 80% train / 20% test
  • Goal: Capture non-linear interaction patterns
MAE5.0199
RMSE7.8983
R²0.8859

Model Conclusion

Linear Regression performed slightly better than Decision Tree on this dataset. It achieved a higher R² value and lower RMSE, which shows that it explained the relationship between student activity and interaction weight more effectively.

Model MAE RMSE R²
Linear Regression 5.1483 7.6487 0.8930
Decision Tree 5.0199 7.8983 0.8859

Overall, Linear Regression is the better model for predicting total interaction weight in this dataset.
