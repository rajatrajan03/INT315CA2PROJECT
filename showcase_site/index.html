Online Learning Platform Interaction Analysis

Project Overview

This project analyzes student interaction networks from online learning data using PySpark, graph-based processing, and basic network analysis.

The work includes cleaning the raw network files, transforming them into student and interaction records, identifying active and isolated students, and producing visual network diagrams for each dataset.
